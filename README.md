# Primeiros passos com HTML

<sub>IS-LUCAS · HTML · CSS</sub>

## Sobre

Estrutura inicial de uma página web, preparada com metadados, uma folha de estilos e um ícone. O arquivo `primeira.html` ainda tem o corpo vazio: é a base do exercício.

## Tecnologias

HTML · CSS

## Conteúdo

| Caminho | Conteúdo |
| --- | --- |
| `primeira.html` | Estrutura inicial da página |
| `Css/style.css` | Folha de estilos |
| `Js/scrip.js` | Arquivo reservado para scripts, ainda vazio |
| `img/logo.png` | Ícone da página |

## Como executar

1. Baixe o repositório em **Code → Download ZIP** e extraia a pasta.
2. Abra `primeira.html` no navegador.
3. Mantenha as pastas de estilos, scripts e imagens junto dos arquivos HTML.

Não é necessário instalar dependências.

Como o corpo da página está vazio, a área de conteúdo aparece em branco.
